Fraud Detection Rules

// how our engine detects suspicious transactions

💰

Rule 1 — High Value Transaction (+40 pts)

Any transaction above ₹50,000 is automatically flagged as potentially fraudulent. Real banks call this "Large Value Transaction Monitoring". Additional +15 pts if above ₹25,000.

⚡

Rule 2 — Rapid Fire / Frequency Check (+45 pts)

4+ transactions within 60 seconds = RAPID_FIRE alert. 2–3 transactions = FREQUENT alert (+25 pts). This detects card testing attacks and account takeovers.

🌙

Rule 3 — Odd Hour Detection (+15 pts)

Transactions between 12:00 AM – 5:00 AM are suspicious. Most fraudulent transactions happen at odd hours when users are sleeping.

🔢

Rule 4 — Round Number Suspicion (+10 pts)

Fraudsters often use round numbers (₹10,000, ₹50,000, ₹1,00,000). Real transactions tend to have odd amounts. Any round amount ≥ ₹10,000 adds suspicion.

📈

Rule 5 — Volume Spike (+20 pts)

If the total money sent in the last 5 minutes exceeds ₹1,00,000, a volume spike alert triggers. This catches coordinated fund-draining attacks.

🧮

Fraud Score Calculation

Score 0–49 = SAFE (green) | Score 50–79 = SUSPICIOUS (orange) | Score 80–100 = HIGH FRAUD RISK (red). A score ≥ 50 triggers a fraud alert modal.
